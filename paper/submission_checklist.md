# OJ-CS Submission Checklist

- [x] Abstract < 250 words
- [x] Keywords included
- [x] Double-column IEEE layout
- [x] Figures readable and labeled
- [x] References follow IEEE numbered format
- [x] Data Availability statement included
- [x] Ethical statement included
- [x] Total page count <= 12 pages
- [x] Supplementary material prepared as a separate file
- [ ] Author affiliations and contact info updated (Requires manual entry by authors)
- [ ] Final visual check on IEEE ScholarOne portal
